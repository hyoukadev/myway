myway

Manage which sites get keyboard shortcuts.

Site rules

Control where myway is active. Each rule matches a URL pattern. Leave Keys blank to disable myway entirely on that site, or list specific keys to pass through to the page.

URL pattern Keys to pass through

Pattern is a URL regex. * matches zero or more characters.
Keys: leave blank = myway off on this site; or type keys (e.g. j) that myway should not capture and pass to the page instead.

Press ? on any page for the full key map.
