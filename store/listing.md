## English

### Name
myway — Keyboard Shortcuts for the Web

### Summary (≤132 chars, Chrome)
Navigate the web with Vim-style keyboard shortcuts — clean defaults, a beautiful settings page,
and a visual key-bindings editor.

### Description

**myway** gives you fast, Vim-style keyboard control of your browser: scroll, jump between
links, switch and manage tabs, search your history and bookmarks, and more — all without reaching
for the mouse.

It's a refined, friendlier take on the classic Vimium extension, rebuilt for modern
Manifest V3 browsers (Chrome, Edge, and Firefox).

✨ **What makes myway different**

- **Cleaner defaults, fewer conflicts.** We removed the Ctrl/Alt shortcuts that clash with your
  browser, OS, and editors (like Ctrl+E, Alt+P), so myway gets along with everything else you
  run.
- **A genuinely nice settings page.** A calm, modern, light/dark UI with grouped sections and a
  responsive layout.
- **A visual key-bindings editor.** Click any shortcut to rebind it with a built-in key
  recorder, search commands by name, show advanced commands, or reset to defaults — no more
  memorizing `map`/`unmap` syntax.

⌨️ **Highlights**

- `j` `k` `h` `l` — scroll the page
- `f` — click any link with a labeled hint
- `o` — open the command bar (search history, bookmarks, tabs, custom engines)
- `J` `K` / `gt` `gT` — switch tabs
- `x` `X` — close / restore a tab
- `?` — open the help dialog and key-bindings editor

🔒 **Private by design.** myway collects no data, includes no analytics or ads, and stores all
settings locally on your device. See the privacy policy for details.

🙏 myway is derived from [Vimium](https://github.com/philc/vimium) (MIT). Full credits are
included with the extension.

### 名称
myway — 网页键盘快捷键

### 简短描述
用 Vim 风格的键盘快捷键浏览网页 —— 默认按键更清爽、设置页更友好、还自带可视化快捷键编辑器。

### 详细描述

**myway** 让你用键盘高效操控浏览器：滚动页面、用标签点链接、切换与管理标签页、搜索
历史与书签……全程无需碰鼠标。

它基于经典插件 Vimium 重新打磨，面向现代 Manifest V3 浏览器（Chrome、Edge、Firefox）。

✨ **myway 的不同之处**

- **默认更清爽，少冲突。** 删除了与浏览器、系统和编辑器（如 Ctrl+E、Alt+P）冲突的
  Ctrl/Alt 快捷键，让 myway 与你已有的工具和平共处。
- **真正好用的设置页。** 现代化的明暗双主题、分组卡片式布局，响应式自适应。
- **可视化快捷键编辑器。** 点任意按键即可重新绑定（内置按键录制器），按名称搜索命令，
  显示高级命令，或一键恢复默认 —— 不用再背 `map`/`unmap` 语法。

⌨️ **常用快捷键**

- `j` `k` `h` `l` —— 滚动页面
- `f` —— 用带字母的提示点任意链接
- `o` —— 打开命令栏（搜索历史、书签、标签页、自定义引擎）
- `J` `K` / `gt` `gT` —— 切换标签页
- `x` `X` —— 关闭 / 恢复标签页
- `?` —— 打开帮助对话框与快捷键编辑器

🔒 **注重隐私。** myway 不收集任何数据，不含任何统计或广告，所有设置仅保存在本地。
