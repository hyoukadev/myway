# myway 变现方案

> 目标:1-2 周内赚 100 元起。核心策略 —— **myway 本身不卖钱,拿它当接单作品集**。

## 一、产品定位(诚实评估)

| 维度 | 事实 |
|------|------|
| 本质 | Vimium(MIT 开源、百万级免费用户)的优化 fork |
| 我们的改动 | ① 去冲突默认键 ② 重做设置页 UI ③ 可视化快捷键编辑器 ④ 多商店打包 |
| 能否直接收费 | **不建议**。竞品全免费,Vim 党不会为 UI 更好看的 fork 付费 |
| 真正的价值 | **极强的工程能力证明** → 用来接定制单 |

## 二、变现路径(按速度排序)

### 🥇 路径 A:接单变现(推荐,1 单完成目标)
myway 证明的能力:浏览器插件全流程(MV3 / service worker / content script)、
中大型代码库二次开发、工程化打包、前端 UI。
客单价 200–1000 元。**1 单 = 目标完成。**

### 🥈 路径 B:上架商店 + 捐赠(被动收入)
爱发电 / GitHub Sponsors。周期:几周到几个月。适合不想花精力时挂上。

### 🥉 路径 C:做付费产品(长期,以月计)
可行的 Pro 付费点:设置云同步 / 团队管理 / 工作流宏 / AI 增强。
周期太长,不适合眼前的 100 元目标。

### ❌ 不做
直接标价卖、加广告、包装成原创(违反 MIT + 风险)。

## 三、接单渠道

| 渠道 | 特点 | 客单价 |
|------|------|--------|
| 闲鱼 | 流量大,"程序员代做"类目 | 50–500 |
| 淘宝 | 需开店,稳定 | 100–1000 |
| 程序员客栈 | 专业、需求高质量 | 500–3000 |
| 码市 / 开源中国众包 | 技术类需求 | 500+ |
| 微信/QQ 技术群 | 口碑转介 | 200–1000 |
| 即构 / Upwork(海外) | 美元结算 | $50–$500 |
